## 🚀 **Getting Started**

### **Prerequisites**
- Node.js 18+ 
- npm or yarn

### **Installation**
```bash
cd fresh-furry-grooming
npm install
```

### **Development**
```bash
npm run dev
```
Visit `http://localhost:3002` to see the mobile-optimized website.

### **Build for Production**
```bash
npm run build
npm run start
```

## 🔧 **Customization**

### **Content Management**
- Edit JSON files in `/content/` directory
- Update service information in `services.json`
- Modify testimonials in `testimonials.json`
- Customize FAQ in `faq.json`

### **Styling**
- Global styles: `/src/styles/globals.css`
- Mobile optimizations: `/src/styles/mobile.css`
- Component styles: Tailwind CSS classes

### **SEO**
- Update metadata in `/src/app/layout.tsx`
- Modify JSON-LD in `/src/components/seo/`
- Configure next-seo in `next-seo.config.ts`
